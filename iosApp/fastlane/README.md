xcode-select --install

# Available Actions

## iOS

### ios screenshots

```sh
[bundle exec] fastlane ios screenshots
```

Captures the App Store screenshots on a connected iPhone (udid:<device id>)

### ios export_screenshots

```sh
[bundle exec] fastlane ios export_screenshots
```

Exports the screenshots from the last `screenshots` run in every App Store size
